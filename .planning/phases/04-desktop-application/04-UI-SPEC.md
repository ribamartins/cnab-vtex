# Phase 4 — UI Design Contract

> Visual and interaction contract for Phase 4: Desktop Application.
> Generated by gsd-ui-researcher. Consumed by gsd-planner, gsd-executor, gsd-ui-auditor.

This phase assembles the full payment workflow GUI in PySide6: dashboard with file list,
CNAB generation flow wired from ValidationReportDialog, file detail dialog with download
and mock transmission, and audit log viewer. All visual decisions extend the design system
established in Phases 2-3 (src/ui/styles.py). No new tokens are introduced.

## Typography

All sizes are QSS `font-size` pixel values. Point sizes use QFont.setPointSize() for titles
only (QFont point sizes are DPI-scaled by Qt). The global QSS baseline is 13px / weight 400.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 13px | 400 (Normal) | Qt default (1.4 approx) | All table cells, form labels, status bar |
| Label/Caption | 12px | 400 (Normal) | Qt default | Error label under buttons, secondary hints |
| Subheading | 13px | 700 (Bold) | Qt default | Table header sections (QHeaderView), section group titles |
| Heading | 14pt (QFont) | 600 (DemiBold) | Qt default | Dialog titles, summary bar in ValidationReportDialog |

Rules:
- Never use more than 2 weights in any single dialog
- Font size 13px is the floor — never go smaller except for the 12px error/caption role
- Primary CTA buttons use 13px bold (already in QSS: `font-weight: bold` on `QPushButton#primary`)
- Status badges use 12px bold colored text (inline QLabel with inline stylesheet)

Source: src/ui/styles.py (font-size: 13px global, QFont.Weight.Bold/DemiBold in login_dialog.py and validation_report_dialog.py)

## Interaction Contracts

### Dashboard table row interaction
- Single click: selects the row (Qt default highlight)
- Double click: opens FileDetailDialog for that row's CnabFile
- Cursor: Qt.CursorShape.PointingHandCursor when hovering any data row
- No right-click context menu

### Filter apply behavior
- Status QComboBox: currentIndexChanged -> immediate table refresh (no Apply button)
- Date QDateEdit: dateChanged -> immediate table refresh
- Filters are AND-combined (status AND date range)
- "Todos" in status dropdown = no status filter applied

### Save As dialog (CNAB download)
- Use QFileDialog.getSaveFileName() with parent=self
- Default directory: last used folder stored in QSettings key "last_save_dir"; fallback to QStandardPaths.DocumentsLocation
- Default filename: pre-populated with the file's stored filename (CNAB_YYYYMMDD_NNN.txt)
- Filter: "Arquivos CNAB (*.txt);;Todos os arquivos (*)"
- On cancel: no action, no error message

### Mock transmission flow
1. "Transmitir" button click -> opens TransmissionConfirmDialog
2. User confirms -> brief QProgressDialog (indeterminate, non-cancellable) while mock runs
3. Success -> QMessageBox.information("Transmissao concluida", "Arquivo transmitido com sucesso.")
4. Status badge in FileDetailDialog updates immediately (reload from DB after commit)
5. Dashboard table refreshes to reflect new status

### CNAB generation flow (wired from ValidationReportDialog)
1. "Gerar CNAB" click -> ValidationReportDialog.accept() -> MainWindow._on_generate() receives valid_payments
2. QProgressDialog (indeterminate) opens: title "Gerando arquivo CNAB...", label "Aguarde..."
3. build_cnab() called synchronously -> CnabFile + Payment rows committed to DB
4. QProgressDialog closes
5. QFileDialog.getSaveFileName() opens immediately (auto-download, D-01)
6. File bytes written to chosen path
7. AuditLog entry created: action="geracao", details="{filename}, {N} pagamentos, R$ {value}"
8. QMessageBox.information("Arquivo gerado", "CNAB gerado e salvo com sucesso.")
9. Dashboard table refreshes

### Error handling states
- CNAB generation failure (rare — DB write or build error): QMessageBox.critical("Erro na geracao", "Nao foi possivel gerar o arquivo CNAB. Detalhes: {error}")
- Download file write failure: QMessageBox.warning("Erro ao salvar", "Nao foi possivel salvar o arquivo. Verifique permissoes e espaco em disco.")
- Mock transmission error path (dev testing only per D-09): status -> "Erro", error_details saved, QMessageBox.critical shown with details
