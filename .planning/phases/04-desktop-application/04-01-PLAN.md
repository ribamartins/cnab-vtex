    ```python

    ```
    Steps:
    - Call `company.to_company_config()` to get CompanyConfig
    - Call `build_cnab(payments, config, payment_date)` to get bytes
    - Create `CnabFile` record: filename=`generate_filename(session)`, file_content=cnab_bytes, status='Criado', row_count=len(payments), total_value_cents=`sum(int(p.value * 100) for p in payments)`, created_by_id=user.id, company_id=company.id
    - Create `Payment` records for each PaymentInput: name=p.name, document=p.document, pix_key=p.pix_key, pix_key_type=p.pix_key_type, value_cents=int(p.value * 100), reference_id=p.reference_id, cnab_file=cnab_file_record
    - session.add(cnab_file_record) — payments cascade via relationship
    - Call `log_audit(session, user.id, 'geracao', f'{filename}, {len(payments)} pagamentos, R$ {format_value(total)}', 'cnab_file', cnab_file_record.id)`
    - session.flush() to get the ID
    - Return the CnabFile object

    from app.cnab_service import generate_cnab_file, log_audit

    company = self._session.query(Company).first()

    file_path, _ = QFileDialog.getSaveFileName(
