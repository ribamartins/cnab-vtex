    **Create `src/app/auth.py`** — Authentication and user management service:

    All functions accept a `session` parameter (SQLAlchemy Session) for testability — no global session state.

    - `authenticate_user(session, username: str, password: str) -> User | None`: Query `User` where `username == username` and `is_active == True`. If found and `user.check_password(password)` is True, return user. Otherwise return None. Never reveal whether username exists (same None for both cases).

    - `create_user(session, username: str, password: str, display_name: str, role: str = 'user') -> User`: Validate password length >= 8 chars (raise `ValueError("A senha deve ter pelo menos 8 caracteres.")`). Check username uniqueness (raise `ValueError("Este nome de usuario ja esta em uso.")`). Validate role in ('admin', 'user') (raise `ValueError("Perfil invalido.")`). Create User, call `set_password(password)`, add to session, flush, return user.

    - `update_user(session, user_id: int, display_name: str | None = None, password: str | None = None, role: str | None = None) -> User`: Fetch user by id. Update only non-None fields. If password provided, validate length >= 8 and call `set_password()`. Flush and return updated user.

    - `deactivate_user(session, user_id: int) -> User`: Set `is_active = False`. Flush and return user. Idempotent — if already inactive, no error.

    - `reactivate_user(session, user_id: int) -> User`: Set `is_active = True`. Flush and return user.

    - `get_all_users(session) -> list[User]`: Return `session.query(User).order_by(User.display_name).all()`.

    - `get_user_by_id(session, user_id: int) -> User | None`: Return `session.query(User).get(user_id)`.

    - `has_any_users(session) -> bool`: Return `session.query(User).first() is not None`. Used by first-run wizard (D-05) to detect empty database.

    - `login_with_session(session, username: str, password: str) -> tuple[User | None, str | None]`: Calls `authenticate_user()`. If successful, calls `create_session_token(user.id)` and `save_session_to_disk(token)`. Returns `(user, token)`. On failure returns `(None, None)`.

    - `restore_session(session) -> User | None`: Calls `load_session_from_disk()`. If token exists, calls `validate_session_token(token)`. If valid user_id, fetches User by id (must be active). Returns User or None. Per D-01 — session restore on app startup.

    - `logout()`: Calls `clear_session_from_disk()`.

    **Create `tests/app/test_auth.py`** — Uses in-memory SQLite. Fixture creates engine + session + tables. Tests all behaviors listed above. Each test creates its own users as needed via direct model creation or `create_user()`.
