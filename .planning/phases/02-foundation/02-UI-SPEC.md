## Design System

| Property | Value |
|----------|-------|
| Tool | none (Qt native QSS) |
| Preset | not applicable |
| Component library | PySide6 Qt widgets — QDialog, QMainWindow, QTabWidget, QTableWidget, QLineEdit, QPushButton, QLabel, QFormLayout |

## Spacing Scale

Qt layouts use pixel margins and spacing. All values are multiples of 4.

| Token | Value | Qt Usage |
|-------|-------|----------|
| xs | 4px | Icon-to-label gap, tight inline padding |
| sm | 8px | Button internal padding (vertical), form field spacing |
| md | 16px | Layout margin (QDialog content margins), between-field spacing |
| lg | 24px | Section separator gap within a form |
| xl | 32px | Dialog minimum padding top/bottom |
| 2xl | 48px | Wizard step vertical breathing room |
| 3xl | 64px | Not used in Phase 2 |

**Qt implementation:** Apply via `setContentsMargins(16, 16, 16, 16)` for QDialog content, `layout.setSpacing(8)` for form rows, `layout.setSpacing(16)` between form groups.

Exceptions:
- Touch targets (buttons, clickable rows): minimum height 32px even when content is smaller — Qt default satisfies this
- Table row height in Users tab: 28px minimum for readability

## Typography

Qt uses system font stack. Declare only size and weight — no font family override.

| Role | Size | Weight | Line Height | Qt API |
|------|------|--------|-------------|--------|
| Body | 13px | Regular (400) | 1.4 | Default QFont (do not override) |
| Label | 13px | Regular (400) | 1.4 | QLabel (default) |
| Heading | 16px | SemiBold (600) | 1.25 | `font.setPointSize(12); font.setWeight(QFont.Weight.DemiBold)` |
| Display | 20px | SemiBold (600) | 1.2 | Wizard title only — `font.setPointSize(15); font.setWeight(QFont.Weight.DemiBold)` |

**Note:** Qt point sizes are platform-dependent. Use `setPointSize()` not `setPixelSize()` for cross-platform consistency. 10pt ≈ 13px on 96dpi Windows. Values above target 96dpi Windows (primary deployment platform).

## Color

Qt QSS color contract. Follows 60/30/10 rule adapted for desktop UI.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F5F5F5` (light gray) | Main window background, dialog background, wizard background |
| Secondary (30%) | `#FFFFFF` (white) | Form panels, QGroupBox interior, table background, input fields |
| Accent (10%) | `#1565C0` (dark blue) | Primary action buttons only (Login, Save, Create Admin, Next) |
| Destructive | `#C62828` (dark red) | Deactivate User button, deactivation confirmation dialog |

Accent reserved for: **primary action buttons only** — "Entrar" (login), "Salvar" (settings save), "Criar Administrador" (wizard submit), "Próximo" (wizard next step). Never used on secondary buttons, links, or labels.

**Semantic status colors (users table only):**

| Status | Color | Usage |
|--------|-------|-------|
| Active user badge | `#2E7D32` (dark green) | "Ativo" badge text in users table |
| Inactive user badge | `#616161` (medium gray) | "Inativo" badge text in users table |

**Error state color:** `#C62828` (same as destructive) — inline validation message text below fields.

**Border color:** `#BDBDBD` — QLineEdit, QGroupBox, QTableWidget borders.

## Interaction Contracts

### Login Dialog

- **Trigger on Enter key:** Pressing Enter in the password field submits the form (same as clicking "Entrar").
- **Error display:** Inline error label below the password field — red text (`#C62828`), 13px, shown after failed attempt. Cleared on next keystroke in either field.
- **Loading state:** "Entrar" button disabled and text changes to "Verificando..." during credential check. Re-enabled on completion.
- **Window behavior:** Fixed size, non-resizable, centered on screen. No minimize/maximize.

### First-Run Setup Wizard

- **Two steps:** Step 1 — Create admin (username + password + confirm password). Step 2 — Company data (all CompanyConfig fields).
- **Step validation:** "Próximo" button only enabled when all Step 1 fields pass inline validation. Cannot advance with errors.
- **No back navigation on Step 2 submit:** Once "Criar Administrador" succeeds, wizard closes and login dialog opens.
- **Password confirmation:** Confirm password field shows error if it does not match the password field, validated on blur.

### Settings Window

- **Tab behavior:** QTabWidget with "Dados da Empresa", "Usuários", and "Credenciais VTEX" tabs. Last active tab is NOT persisted across sessions — always opens on "Dados da Empresa".
- **Unsaved changes guard:** If user switches tabs or closes window with unsaved edits, show a QMessageBox: "Há alterações não salvas. Deseja salvar antes de sair?" — buttons: "Salvar", "Descartar", "Cancelar".
- **Credential fields:** VTEX AppKey and AppToken displayed as password-masked fields (QLineEdit with echoMode PasswordEchoOnEdit). "Mostrar" toggle button unhides for 5 seconds then auto-re-masks.

### Users Table (Settings → Usuários tab)

- **Columns:** Nome, Usuário, Perfil (Admin/Usuário), Status (Ativo/Inativo), Ações.
- **Actions column:** Two icon-text buttons per row — "Editar" and "Desativar" (or "Reativar" if inactive). Destructive "Desativar" uses `#C62828` text color.
- **Deactivate confirmation:** QMessageBox with "Sim, desativar" (red button) and "Cancelar".
- **Cannot deactivate self:** If the logged-in admin selects their own account, "Desativar" is disabled (grayed) with tooltip: "Não é possível desativar sua própria conta."
- **Add User dialog:** Opens as a QDialog modal with username, password, confirm password, and role (QComboBox: "Usuário" / "Administrador") fields.
