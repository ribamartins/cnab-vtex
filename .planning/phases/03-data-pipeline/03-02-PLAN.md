    3. `enriched_payments = [r.payment for r in enriched]`

    5. Build `validation_error_indices = {ve.row for ve in validation_errors}` — these are indices into the enriched_payments list
    6. `valid_rows = [p for i, p in enumerate(enriched_payments) if i not in validation_error_indices]`
    7. `self._valid_payments = valid_rows`
    8. Compute: `valid_count = len(valid_rows)`, `error_count = len(vtex_errors) + len(validation_errors)`, `total_count = len(results)`, `valid_total = sum((p.value for p in valid_rows), Decimal("0"))`
